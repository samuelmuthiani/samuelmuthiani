# Samuel Muthiani Counseling Site

A responsive, single-page website preview built as a standalone HTML file.

## Preview locally

Open `index.html` in a browser, or run `python -m http.server 8000` from this folder and visit <http://127.0.0.1:8000>.

## Included interactions

- Support picker, breathing exercise, light/dark theme toggle, FAQ, and message preparation form.
- The form runs in the browser and does not transmit or save entries.

## Before launch

Replace the phone, email, location, and portrait placeholders. Confirm credentials, rates, availability, and service details before publishing this page as a live practice website.
